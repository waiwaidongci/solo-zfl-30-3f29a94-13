# 铭文转录与校勘台（离线）

为水下考古文字资料员设计的**完全离线**铭文转录与校勘工作站：按
**载体 → 版面 → 行/列 → 字位** 录入原貌字、通读字、缺损、书写方向与候选释读；
批注与行间对应以**字位稳定编号（uid）锚定**；支持任意两份抄本的**逐字校勘**与
**可检索字形索引**。纯静态、零运行时依赖，数据只存在本机（localStorage / 导出 JSON）。

## 运行

需要 Node 18+（仅为本地静态服务器与测试；浏览器中运行无任何外部依赖）。

```bash
npm install          # 仅安装开发依赖 Playwright（运行应用本身不需要）
npm start            # http://localhost:8123
```

也可以直接用浏览器打开 `index.html`（ES Modules 在个别浏览器下需经 http 访问，推荐用上面的服务器）。

## 功能

### 录入与显示
- **字位按 Unicode 字素簇计数**（`Intl.Segmenter`）：组合字符（`e` + U+0301）、ZWJ emoji、
  谚文音节、代理对生僻字（如 U+23A98）都恰好占一个字位；检视器实时显示字素簇数。
- 字位类型：**普通字 / 合文**（一位多字，如「玟＝文王」）/ **缺字占位**（`□`，可标应有字数）。
- 每字位记录：原貌字、通读字/释文、缺损（残/泐/蚀/漫漶）、候选释读（含把握度）、备注。
- **书写方向**：横排左至右、横排右至左、竖排右至左、竖排左至右，由 CSS 真实排版
  （`flex-direction: row-reverse` / `column`）；双向混排文本用 `unicode-bidi: plaintext` 正确视觉重排。
- 字位可在行间插入、删除、拖拽/检视器移位；合文双线框、缺字斜纹底、缺损红色角标。

### 锚定批注与行间对应
- 批注锚点是 **uid 列表**，可跨字、跨行/列；「点选锚点」模式下逐字点选，转录区显示彩色锚点序号。
- **文字增删或移位后，批注与行间对应仍锚定原字符**（顺序变、uid 不变）。
- 行间对应可建立两行的字位配对（如「锡贝 ↔ 作器」），配对同样以 uid 锚定。
- 批注可声明行范围；校勘释文符号限定 `〔…〕`（增补）、`（…）`（拟补）、`〈…〉`（改正），
  须成对、不得嵌套、对内非空；`□`（缺字）、`○`（空字）为合法单字符号。

### 逐项校验（「校验」标签，顶栏徽标计数）
- **悬空引用**：批注/对应引用了已删除的字位或行（报出批注、第几个锚点、缺失 id）。
- **越界批注**：锚点跨行却声明限本行；同行内锚点隔字不连续。
- **互斥释读**：同一字位多于一个「采纳」候选；采纳候选为空。
- **非法校勘符号**：`【】〖〗｛｝{}[]«»？?＊*` 等逐字定位（给出字素簇序号）；
  括号未闭合、失配、嵌套、空括号分别报错。
- 字位内容规则：普通字原貌须恰为 1 个字素簇；缺字占位不得有原貌字、应有字数须 ≥1；
  合文通读不足两字 / 普通字通读多字给出警告。
- 点击任一问题跳转到对应字位或批注卡片。

### 逐字校勘
- 任选两份抄本，按阅读顺序做**字素簇级 Myers（LCS）对齐**，平局时用前瞻启发式
  （某字在对方后段仍出现则保留待配）避免把「段中增补」错配成替换。
- 结果逐行分四类：**相同 / 替换 / 增补（乙有甲无）/ 脱文（甲有乙无）**，
  缺字占位展开为 `□` 参与对齐；每行附甲/乙所在行与字位号。
- 比字口径可切换：首选释读（采纳候选 ＞ 通读字 ＞ 原貌字）或仅原貌字。

### 字形索引
- 以字素簇为键，汇总**原貌字、通读字、候选释读**中的每次出现，标注载体/版面/行/字位与缺损；
  缺字占位不入索引。支持精确/前缀/包含检索与按缺损过滤，点击出处跳到字位。

### 数据
- 顶栏「导入 / 导出」整个工作区 JSON；「示例」恢复内置示例（一件竖排右至左青铜簋铭文，
  含合文、缺字、缺损、候选、跨字与跨行批注、行间对应；另附两份用于校勘的抄本）。

## 目录

```
index.html                 入口
styles.css                 竖排/RTL/合文/缺字/缺损/批注样式
src/core/
  graphemes.mjs            字素簇切分
  model.mjs                数据模型 + 增删移位（uid 不变）
  annotations.mjs          批注/行间对应 + 符号文法 + 逐项校验
  collation.mjs            方向规整 + Myers 对齐（相同/替换/增补/脱文）
  index.mjs                字形索引与检索
  sample.mjs               示例工作区
src/ui/                    原生 DOM 界面（无框架）
tools/server.mjs           零依赖静态服务器
tests/                     node --test 单元测试（37）
tests/browser/             Playwright 真实 Chromium 测试（16）
```

## 测试

```bash
npm test                   # Node 单元测试：字素簇/模型锚定/校验/校勘/索引
npm run test:browser       # 真实 Chromium：组合字几何、bidi 重排、竖排 RTL、
                           # 插删重排锚定、悬空/越界/互斥/非法符号定位、校勘四类、索引
npm run test:all           # 两者皆跑
```

浏览器测试以**真实几何**核验（不是仅断言数据）：组合字符渲染宽度、Range 边界框验证
阿拉伯文/拉丁视觉次序、列与字位的 x/y 坐标验证竖排右至左。

### 无 root 环境准备
若容器内没有 Chromium 运行库或中文字体（本机即如此），无需 root：

```bash
npx playwright install chromium
# 运行库：apt-get download 各 deb 后 dpkg-deb -x 到同一目录，
# 由 playwright.config.js 以 LD_LIBRARY_PATH 注入（默认探测 /tmp/rootfs 的多架构 lib 目录）
# 中文字体：把文泉驿 ttc 放到 ~/.fonts 后 fc-cache -f ~/.fonts
```

`playwright.config.js` 仅在这些本地目录存在时注入，不影响普通环境。
